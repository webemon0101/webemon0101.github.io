- `index.html` … トップページ（HAMZWORKERZ GAMES メニュー、`games/` 配下の各ゲームへのリンク）
- `about.html` … 運営者情報
- `privacy.html` … プライバシーポリシー
- `ads.txt` … AdSense のサイト認証（ドメイン直下でしか読まれないためここに配置）
- `archive/progate/` … 旧・Progate 練習ページ（保管）
- `archive/trans3/`（`stylesheet.css`, `speech.js`, `honyakuButton.js`, 各種画像） … 音声翻訳アプリ「ほんやくこんにゃく」（元トップページ、保管。AdSense審査がコンテンツ不足で通らなかったため撤去）

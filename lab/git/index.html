Git 体験

ブラウザの中に、練習用の Git を用意しました。本物のファイルやリポジトリは壊れません。右の「ミッション」を上から順に進めると、Git の基本が一通り体験できます。

① 作業フォルダ

ふだんファイルを書く場所
→git add

② ステージ

次の記録に入れるものを置く場所
→git commit

③ 履歴

記録（コミット）が積み重なる場所
✏️ を編集
ターミナル（help でコマンド一覧）
$
ミッション

左の ①〜③ の図は、コマンドを打つたびに変わります。①のファイルを押すと、中身を書き換えられます。色の意味: 灰＝Git がまだ知らない / 橙＝記録から変わった / 緑＝次の記録に入れる予定

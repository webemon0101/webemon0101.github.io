MCP 体験

MCP（Model Context Protocol）は、AI が外の「道具」を使うための共通のつなぎ方です。AI と道具の間で、裏でどんなやりとりが流れるかを、1歩ずつ「次へ」で進めて見てみましょう。ここでは本物の AI は動いていません。仕組みを再現した模擬です。

あなたAI に質問する人。
AI アプリ（ホスト／クライアント）質問を理解して、道具が要るか決め、道具を呼ぶ側。
MCP サーバー道具を持っている側。天気・計算・メモなどの「できること」を公開する。
① AI に聞いてみる
② やりとりの流れ（カードを押すと、右に詳しく出ます）
③ いま何が起きている？
本物との違い：本物の MCP では、サーバーは別のプログラム（自分のパソコンで動くものや、ネット上のサービス）で、メッセージは「JSON-RPC 2.0」という形式で、標準入出力または HTTP を通じて送られます。この画面のメッセージの形は、その形式に沿っています。ただし、AI が「どの道具を使うか」を決める部分は、本物では言語モデルが行います。ここでは簡単なルールで再現しています。MCP の仕様は更新されるため、細部は最新の仕様でご確認ください。

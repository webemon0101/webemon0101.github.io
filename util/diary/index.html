ふだんは同期しなくても使えます。PCとスマホで同じ日記を見たい人だけ、下の手順で自分専用のデータ置き場（Googleの Firebase・無料枠）を作ってつなぎます。記録はあなた自身のFirebaseに保存され、運営者には届きません。所要時間は10分ほどです。

  1. Firebaseコンソールを開き、Googleアカウントでログイン →「プロジェクトを追加」→ 名前（例：my-diary）を入れ、Googleアナリティクスはオフのまま作成します。
  2. 左メニュー「構築」→「Authentication」→「始める」→「Sign-in method」→「Google」を有効にして、サポートメールを選んで保存します。
  3. Authentication の「設定」→「承認済みドメイン」→「ドメインを追加」で、 を追加します。（これを忘れるとログインできません）
  4. 左メニュー「Firestore Database」→「データベースを作成」→ ロケーションは asia-northeast1（東京） → 「本番環境モード」で作成します。
  5. Firestore の「ルール」タブの中身をすべて消して、下のルールを貼り付け →「公開」を押します。 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  6. 左上の歯車 →「プロジェクトの設定」→「全般」→ 下の「マイアプリ」でウェブ（</>）のアイコンを押し、ニックネームを入れて登録します（Hostingのチェックは不要）。表示される firebaseConfig = { … } の部分をコピーします。
  7. 下の欄に貼り付けて「保存して接続」→「Googleでログイン」を押します。これで同期が始まります。
  8. もう1台（スマホ／PC）でも、このページを開いて同じ欄に貼ります。「設定コードをコピー」で作れるコードを貼ってもOKです。同じGoogleアカウントでログインすれば、記録がそろいます。
合言葉を決めると、Firebaseに置かれる本文・カテゴリー名はこの端末で暗号化され、あなたにも合言葉なしでは読めません。忘れると復元できません。どの端末にも同じ合言葉を入れてください。最初の接続のときだけ決められます（あとから変更はできません）。

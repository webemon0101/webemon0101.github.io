画像の容量・形式かえるくん

写真や画像の「ファイルサイズ（容量）」「形式（JPEG / PNG / WebP など）」「大きさ（ピクセル）」をまとめて変えます。処理はすべてブラウザ内で行われ、画像はアップロードされません。

ここに画像をドラッグ＆ドロップ（複数OK）
クリックして選ぶ、または Ctrl+V で貼り付け
JPEG / PNG / WebP / GIF（1コマ目）/ BMP / SVG など、ブラウザで開ける画像

変換の設定（変えると、読み込み済みの画像をすぐ作り直します）

目標サイズは JPEG / WebP / AVIF で画質を自動調整します。PNG は画質を変えられないので、縮小で近づけます。
出力すると、撮影場所・日時などのメタデータ（EXIF）は消えます。スマホ写真の向きは、正しい向きに直してから保存します。

結果

まだ画像がありません。

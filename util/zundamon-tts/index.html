自分のPCの VOICEVOX を使うには（初回だけ設定）

1. VOICEVOX を起動します。

2. ブラウザで http://127.0.0.1:50021 を開き、「設定」を押します。

3. 「CORS Policy Mode」を all にして保存します（localapps のまま「Allow Origin」に を入れても可）。

4. ブラウザではなく、VOICEVOX 本体（アプリ）の上部メニュー「エンジン → 再起動」を押してエンジンを再起動します。

5. このページを再読み込みすると、全キャラクターが選べるようになります。ブラウザが「ローカルネットワークへのアクセス」を確認してきたら許可してください。

Web API は文字数・回数の制限があり、話速などの細かい調整はできません。
